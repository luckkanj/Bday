# เว็บเซอร์ไพรส์วันเกิด · 3 ตุลาคม 2569

เว็บหน้าเดียว เปิดบนมือถือ เดินเรื่องเอง 6 ฉาก

```
ซองจดหมาย → จดหมาย → ปฏิทิน → อัป 3 ดาว → พลุ+หัวใจ → สไลด์รูป → ปิดท้าย
```

---

## สิ่งที่ต้องทำก่อนส่ง

### 1. ใส่รูปและวิดีโอ

เอารูปกับคลิปจากมือถือมาวางในโฟลเดอร์ `_ต้นฉบับ/` **ลงดิบได้เลย ไม่ต้องแปลงอะไรก่อน**
ตั้งชื่อนำหน้าด้วยเลขเพื่อกำหนดลำดับ เช่น `1-เจอกันครั้งแรก.jpg` `2-ไปทะเล.MOV` แล้วรัน

```bash
cd ~/ส่วนตัว/bday
python3 เตรียมสื่อ.py
```

สคริปต์สร้าง `img/01.jpg` และ `vid/02.mp4` ให้ตามลำดับ
แล้วพิมพ์บล็อกโค้ดออกมาให้ก๊อปไปวางใน `content.js`

**รูป** — ย่อเหลือใบละ ~200 KB และหมุนรูปตะแคงที่ iPhone ชอบทำให้ด้วย

**วิดีโอ** — ต้องมี `ffmpeg` ก่อน (`sudo apt install ffmpeg`) สคริปต์จะ
แปลง HEVC ของไอโฟนเป็น H.264 (ไม่งั้น Chrome บน Android เห็นจอดำ) ·
ย่อเหลือ 720p · **ตัดเสียงทิ้ง** เพราะมือถืออนุญาตให้เล่นอัตโนมัติเฉพาะคลิปเงียบ
และเรามีเพลงประกอบอยู่แล้ว · คลิปควรยาวไม่เกิน 8–10 วินาที

### 2. เขียนข้อความ

แก้ไฟล์ `content.js` ไฟล์เดียว — **ไม่ต้องแตะไฟล์อื่นเลย**
ในนั้นมีคอมเมนต์บอกไว้ทุกช่องว่าอันไหนคืออะไร

กติกาเดียวที่ต้องระวัง: ข้อความต้องอยู่ในเครื่องหมาย `" "` และทุกบรรทัดจบด้วย `,`

### 3. ใส่เพลง

เอาไฟล์ mp3 ไปวางเป็น `audio/song.mp3` (ทับไฟล์เดิมได้เลย)
ถ้าชื่อไฟล์ไม่ตรง ให้แก้ช่อง `เพลง.ไฟล์` ใน `content.js`

เพลงจะเริ่มเล่นตอนแตะเปิดซอง — ไม่ใช่ตอนโหลดหน้า เพราะมือถือบล็อกการเล่นอัตโนมัติ
ถ้ายังไม่มีเพลง เว็บก็ทำงานปกติ แค่เงียบ

### 4. ดูตัวอย่างก่อนส่ง

```bash
cd ~/ส่วนตัว/bday
python3 -m http.server 8899
```

แล้วเปิด `http://localhost:8899/` ในเบราว์เซอร์

**ทางลัดดูเฉพาะฉาก** — ต่อท้าย URL ว่า `?ดู=ชื่อฉาก` จะได้ไม่ต้องไล่คลิกใหม่ทุกครั้ง

| ทางลัด | ฉาก |
|---|---|
| `?ดู=จดหมาย` | จดหมาย |
| `?ดู=ปฏิทิน` | ปฏิทิน |
| `?ดู=สามดาว` | อัป 3 ดาว |
| `?ดู=พลุ` | พลุ + หัวใจ |
| `?ดู=สไลด์` | สไลด์รูป |
| `?ดู=ปิดท้าย` | ปิดท้าย |

## หมายเหตุทางเทคนิค

- **ไม่มี build step** เป็น HTML/CSS/JS ล้วน แก้ไฟล์แล้วรีเฟรชเห็นผลทันที
- **ตัวละครทั้งหมดวาดเป็น SVG ในโค้ด** ไม่มีไฟล์ภาพจากเกมใด ๆ ไม่ติดลิขสิทธิ์ใคร
- **โฟลเดอร์นี้อยู่ลึกหนึ่งชั้นโดยตั้งใจ** — `~/bin/backup-repos.sh` วนหาเฉพาะ repo
  ที่เป็นลูกชั้นเดียวของ `~` โปรเจกต์นี้จึงไม่ถูกสำรองขึ้น Google Drive ของที่ทำงาน
- `_ต้นฉบับ/` อยู่ใน `.gitignore` รูปดิบไม่ถูกอัปขึ้น GitHub
- `robots.txt` กับ meta `noindex` กันกูเกิลเก็บหน้านี้เข้าสารบัญ
- ไฟล์ `_test-*.html` เป็นของสำหรับตรวจงานเท่านั้น **ไม่ต้องลบ** — อยู่ใน
  `.gitignore` แล้ว จึงไม่เคยขึ้นเว็บอยู่แล้ว (เดิมเขียนว่าให้ลบก่อนอัป ซึ่งตกยุคไปแล้ว)
- `_test-จังหวะ.py` เป็นตัววัดเวลาจริงจากหน้าเว็บ ใช้ยืนยันว่าจังหวะที่ตั้งไว้
  ออกมาตรงจริง · ต้องเปิด `python3 -m http.server 8899` ค้างไว้ก่อนรัน
