# เว็บเซอร์ไพรส์วันเกิด · 3 ตุลาคม 2569

เว็บหน้าเดียว เปิดบนมือถือ เดินเรื่องเอง 6 ฉาก

```
ซองจดหมาย → จดหมาย → ปฏิทิน → อัป 3 ดาว → พลุ+หัวใจ → สไลด์รูป → ปิดท้าย
```

---

## สิ่งที่ต้องทำก่อนส่ง

### 1. ใส่รูป

เอารูปจากมือถือมาวางในโฟลเดอร์ `_ต้นฉบับ/` ตั้งชื่อนำหน้าด้วยเลขเพื่อกำหนดลำดับ
เช่น `1-เจอกันครั้งแรก.jpg` `2-ไปทะเล.jpg` แล้วรัน

```bash
cd ~/ส่วนตัว/bday
python3 ย่อรูป.py
```

สคริปต์จะย่อรูปให้เหลือใบละ ~200 KB สร้างเป็น `img/01.jpg` `img/02.jpg` ...
แล้วพิมพ์บล็อกโค้ดออกมาให้ก๊อปไปวางใน `content.js`

> ทำไมต้องย่อ: รูปมือถือใบละ 3–5 MB ถ้าอัปดิบ ๆ คนเปิดบนเน็ตมือถือจะรอนานมาก
> และสคริปต์ยังแก้รูปตะแคงที่ iPhone ชอบทำให้ด้วย

### 2. เขียนข้อความ

แก้ไฟล์ `content.js` ไฟล์เดียว — **ไม่ต้องแตะไฟล์อื่นเลย**
ในนั้นมีคอมเมนต์บอกไว้ทุกช่องว่าอันไหนคืออะไร

กติกาเดียวที่ต้องระวัง: ข้อความต้องอยู่ในเครื่องหมาย `" "` และทุกบรรทัดจบด้วย `,`

### 3. ใส่เพลง

เอาไฟล์ mp3 ไปวางเป็น `audio/song.mp3` (ทับไฟล์เดิมได้เลย)
ถ้าชื่อไฟล์ไม่ตรง ให้แก้ช่อง `เพลง.ไฟล์` ใน `content.js`

เพลงจะเริ่มเล่นตอนแตะเปิดซอง — ไม่ใช่ตอนโหลดหน้า เพราะมือถือบล็อกการเล่นอัตโนมัติ
ถ้ายังไม่มีเพลง เว็บก็ทำงานปกติ แค่เงียบ

### 4. ดูตัวอย่างก่อนส่ง

```bash
cd ~/ส่วนตัว/bday
python3 -m http.server 8899
```

แล้วเปิด `http://localhost:8899/` ในเบราว์เซอร์

**ทางลัดดูเฉพาะฉาก** — ต่อท้าย URL ว่า `?ดู=ชื่อฉาก` จะได้ไม่ต้องไล่คลิกใหม่ทุกครั้ง

| ทางลัด | ฉาก |
|---|---|
| `?ดู=จดหมาย` | จดหมาย |
| `?ดู=ปฏิทิน` | ปฏิทิน |
| `?ดู=สามดาว` | อัป 3 ดาว |
| `?ดู=พลุ` | พลุ + หัวใจ |
| `?ดู=สไลด์` | สไลด์รูป |
| `?ดู=ปิดท้าย` | ปิดท้าย |

## วิธีอัปขึ้นเว็บ (GitHub Pages)

ครั้งแรก:

```bash
cd ~/ส่วนตัว/bday
git init
git config user.name  "luckkanj"
git config user.email "luckkana.jareanyong@gmail.com"
git add .

git branch -M main
git remote add origin https://github.com/luckkanj/<ชื่อ-repo>.git
git push -u origin main
```

แล้วไปที่ **Settings → Pages → Source: main / (root) → Save**
รอ 1–2 นาที ลิงก์จะขึ้นที่ `https://luckkanj.github.io/<ชื่อ-repo>/`

แก้อะไรทีหลังแล้วอัปใหม่:

```bash
git add . && git commit -m "แก้ข้อความ" && git push
```

## วิธีลบทิ้งหลังใช้เสร็จ

ทำทันทีหลังวันเกิด เพราะ repo เป็นสาธารณะ

1. ไปที่ `https://github.com/luckkanj/<ชื่อ-repo>/settings`
2. เลื่อนลงล่างสุด → **Delete this repository** → พิมพ์ชื่อ repo ยืนยัน
3. ลบ repo แล้วลิงก์จะตายทันที รูปทั้งหมดหายไปด้วย

ถ้าอยากลบให้หมดจริง ๆ ลบบัญชี GitHub ทั้งบัญชีได้ที่ **Settings → Delete account**

> ไฟล์ในเครื่องที่ `~/ส่วนตัว/bday/` ยังอยู่ ลบ repo บนเว็บไม่ได้ลบของในเครื่อง

## หมายเหตุทางเทคนิค

- **ไม่มี build step** เป็น HTML/CSS/JS ล้วน แก้ไฟล์แล้วรีเฟรชเห็นผลทันที
- **ตัวละครทั้งหมดวาดเป็น SVG ในโค้ด** ไม่มีไฟล์ภาพจากเกมใด ๆ ไม่ติดลิขสิทธิ์ใคร
- **โฟลเดอร์นี้อยู่ลึกหนึ่งชั้นโดยตั้งใจ** — `~/bin/backup-repos.sh` วนหาเฉพาะ repo
  ที่เป็นลูกชั้นเดียวของ `~` โปรเจกต์นี้จึงไม่ถูกสำรองขึ้น Google Drive ของที่ทำงาน
- `_ต้นฉบับ/` อยู่ใน `.gitignore` รูปดิบไม่ถูกอัปขึ้น GitHub
- `robots.txt` กับ meta `noindex` กันกูเกิลเก็บหน้านี้เข้าสารบัญ
- ไฟล์ `_test-*.html` เป็นของสำหรับตรวจงานเท่านั้น **ลบทิ้งก่อนอัปขึ้นเว็บ**
